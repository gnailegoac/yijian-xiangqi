# 界面零件的临时脚本（归档）

这里是重构期间各个界面零件留下的临时脚本，原样归档，**不参与构建、类型检查和任何测试**，也没有人维护。

- 每个文件夹是一个零件：`X1` 到 `X8`、`XC`、`XD` 是界面的各个部分（棋盘、特效、音效、军师形象、对话区、按钮与弹层等），`G4` 是对局流程，`A1` 是程序入口，`PF` 是试玩后的打磨，`FA` 是结束审查之后的对局流程修正。零件各自做了什么，见上一级的 `WAVE<n>-NOTES.md`。
- 内容大多是用系统里的 Chrome 打开页面做检查、截图、量时间的脚本，也夹着一些一次性的修改脚本和小工具。`review/` 子文件夹是复核人写的。
- 这些检查没有改写成正式的端到端测试（`tests/e2e/` 只有契约 14.7 节的 21 个流程），留在这里是为了以后查得到当时是怎么验证的。见 `CONTRACT-NOTES.md` 第 134 条 (a) 和第 153 条。
- 脚本里的路径是当时那台机器上的：系统用户名换成了 `USERNAME`（短路径是 `USERNA~1`），临时目录也早已不在。要重新运行，得先把路径和端口改成自己的。
- 没有归档的：截图、日志、整棵源码的副本，以及变异测试生成的成批副本。
