# 设计文档（备份）

这里是「孩子版」重构的设计文档备份。它不参与构建，也不会被发布到 `dist/`。

- `SPEC.md`：构建契约（已冻结），目录和行号见 `SPEC-TOC.txt`。
- `CONTRACT-NOTES.md`：对契约的解读和历次决定（A 到 R 节，第 1 到 153 条）。
- `WAVE<n>-NOTES.md`：每一波零件完成后的记录：各零件选定的解读、对后续零件的要求、没有验证的事项。`WAVE6-NOTES.md` 是第 5 波之后四个修正包（PG、RT、FA、FB）的记录。
- `tools/`：构建期间用的辅助脚本和工作流脚本。
- `browser-checks/`：各个界面零件留下的临时脚本（浏览器检查、截图、量时间），原样归档，不参与构建和测试，见其中的 README。

重构进行期间，工作副本在本机的临时目录里，这里的文件在每一波结束后同步一次，所以可能比工作副本旧。请不要直接改这里的文件。

这里的文件由 `tools/sync-docs.mjs` 从工作副本生成。生成时，路径里的系统用户名换成了 `USERNAME`（短路径是 `USERNA~1`），网关地址换成了 `gateway.example.com`。要重新运行 `tools/` 里的脚本，先把这些路径改回实际的值。
